# i18n & 翻译指南

PLand 支持多语言。本文分为两部分：

- **开发者部分**：如何在你的附属插件中使用 PLand 的翻译机制
- **贡献者部分**：如何为 PLand 翻译新语言

## 开发者：使用翻译

PLand 基于 **fmt** 库和 LeviLamina 的 i18n 机制实现多语言。在代码中，只需要在字符串字面量后加上 `_tr` 或 `_trl` 后缀即可。

::: warning 重要：`_tr` / `_trl` 返回的是一个**函数**，必须调用！
- `"字符串"_tr` 返回函数，需要用 `()` 调用：`"字符串"_tr()`
- `_tr` 的完整形式为 `_tr(format_args...)`，`format_args` 是**可选的格式化参数**，可以不传
- `_trl` 的完整形式为 `_trl(localeCode, format_args...)`：**第一个参数是语言代码**，后面的格式化参数可选
:::

### `_tr`（使用当前语言）

```cpp
#include "pland/Global.h" // _tr / _trl 已在这里引入

// 无格式化参数：必须带 () 调用
player.sendMessage("欢迎来到领地！"_tr());

// 带格式化参数（fmt 占位符）
player.sendMessage("你的余额不足，还差 {} 元"_tr(1000));
```

### `_trl`（指定语言）

```cpp
// 语言代码为第一个参数，格式化参数可选（不要二次调用括号）
auto msg  = "欢迎来到领地！"_trl(localeCode);
auto msg2 = "你的余额不足，还差 {} 元"_trl(localeCode, 1000);
```

### fmt 占位符

翻译字符串使用 **fmt 占位符**，`{}` 表示参数：

```cpp
"我是{}，来自{}"_tr("abc", "xxx")  // 格式化后为 "我是abc，来自xxx"
```

::: tip 占位符进阶
`{}` 或者 `{0}` 中的数字表示第几个参数（从 0 开始）。  
例如 `"来自 {1} 的 {0}"` 格式化后为 `"来自 xxx 的 abc"`。
:::

## 翻译文件格式

::: warning 插件默认提供简体中文为默认语言，您可以在 `plugins/PLand/lang` 下找到默认的翻译文件
:::

::: tip 翻译文件的格式为 `json`，其中 `key` 为原句, `value` 为翻译后的句子
:::

- zh_CN => en_US

```json
{
  "我是{}，来自{}": "I am {}, from {}"
}
```

::: warning 翻译时，您无需修改键，修改后会导致 `i18n` 找不到对应的翻译，从而使用内置的翻译
:::

## 关于贡献

::: tip 我们非常欢迎您为插件贡献翻译，但请注意以下几点：
:::

1. 不要减少、删除占位符，除非您知道这样做不会影响翻译
2. PR 时，请提交到 `assets/lang` 文件夹下
3. Pr 前，请先进行测试，确保占位符正常工作
