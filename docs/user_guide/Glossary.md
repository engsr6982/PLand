# 术语表

> 第一次接触 PLand？先花一分钟了解下面这些基础概念，后面的文档就好懂多了。
> 每个术语都标注了对应的英文，方便你在配置、指令或与开发者交流时对照。

## 核心概念

### 领地（Land）

PLand 的核心概念：一块被玩家"圈"下来、受权限保护的长方体区域。在这块区域内，非主人/成员的行为会受到权限限制（如不能破坏方块、不能开箱子等）。

一个领地包含：**范围（AABB）**、**主人（Owner）**、**成员（Members）**、**权限表（PermTable）** 等信息。

### 选区（Selection）

你通过选点工具（默认木棍）框出来的**临时范围**。选区不是领地，只有完成创建后才会成为领地。

- **A 点 / B 点**：选区的两个对角点。A、B 两点之间的长方体就是选区范围。
- **选区工具**：默认是木棍，可在配置中修改（`selector.item`）。

### 3D 领地 / 2D 领地

- **3D 领地**：完整的立体区域（包含 Y 轴高度），适合圈楼房、矿洞等。
- **2D 领地**：仅包含 X/Z 平面的区域（从上到下贯穿整个维度高度），适合圈地面地盘。

## 权限相关

### 权限等级（LandRole）

领地内的玩家按身份分为 4 个等级，权限从高到低：

| 等级 | 说明 |
|:----|:----|
| **Operator** | 操作员（服务器管理员），拥有所有权限，不受领地限制 |
| **Owner** | 领地主人，拥有领地内全部权限 |
| **Member** | 领地成员，拥有领地内部分权限（是否破坏、是否开箱等由权限表决定） |
| **Actor** | 其他玩家（访客）与生物，拥有领地内最少的权限 |

### 权限表（PermTable）

每个领地都有一张权限表，决定**成员（Member）**和**访客（Actor）**在领地内能做什么：

- **环境权限（EnvironmentPerms）**：控制闪电、液体流动、苔藓生长、爆炸等环境行为
- **角色权限（RolePerms）**：控制玩家动作，如破坏方块、放置方块、使用容器、PvP 等

::: tip 想了解有哪些权限？
完整权限列表见 [拦截器配置文件的可用权限值](/user_guide/InterceptorConfig#可用的权限值)。
:::

## 交易相关

### 买断制（Bought）

一次性付清价格，**永久拥有**领地。适合固定地盘。

- 相关配置：`business.bought`

### 租赁制（Leased）

**按天付费**租用领地，到期后进入冻结期，逾期不续费则被回收。适合临时地盘。

- 相关配置：`business.leasing`

### 价格公式（Formula）

计算领地价格的**数学表达式**，可以使用面积、高度等变量动态定价。

- 例如 `square * 8 + height * 20` 表示"面积 × 8 + 高度 × 20"
- 完整说明见 [领地配置文件：formula 价格表达式](/user_guide/Config#formula-价格表达式)

### 冻结（Freeze）

租赁领地到期后进入**冻结期**。冻结期内领地被锁定（无法正常使用），续费后恢复。逾期仍不续费则触发回收。

### 回收（Recycle）

租赁领地因逾期等原因被系统收回。回收方式由配置决定：

- **TransferToSystem**：领地转给系统账户（可用于后续转卖）
- **Delete**：直接删除领地

## 领地关系

### 子领地（Sub Land）

在**父领地**内部划分的小块领地。子领地独立于父领地，拥有自己的主人、成员和权限。

### 父领地（Parent Land）

拥有子领地的领地。父领地和子领地一起形成**领地树**结构，最多嵌套 16 层。

| 领地类型 | 有父领地 | 有子领地 |
|:--------|:-------:|:-------:|
| 普通领地 | × | × |
| 父领地 | × | √ |
| 混合领地 | √ | √ |
| 子领地 | √ | × |

::: tip 更多细节
关于子领地的使用规则见 [FAQ：关于子领地](/user_guide/FAQ#关于子领地)。
:::

## 其他

### 传送点（Teleport Pos）

领地指定的传送位置。开启领地传送后（`features.landTeleport`），玩家可以传送到这里。

### 维度（Dimension）

Minecraft 的各个世界，常见维度 ID：

| ID | 维度 |
|:--:|:----|
| 0 | 主世界（Overworld） |
| 1 | 下界（Nether） |
| 2 | 末地（The End） |

### 拦截器（Interceptor）

PLand 用于强制领地权限的底层机制：通过监听游戏事件（如破坏方块、开箱子、爆炸等）来阻止越权行为。

- 相关配置见 [拦截器配置文件](/user_guide/InterceptorConfig)

### 数据库快照（Snapshot）

对领地数据库（LevelDB）的**备份**。快照保存到 `plugins/PLand/data/snapshots/<名称>` 目录，可用于数据恢复。
