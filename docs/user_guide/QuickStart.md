# 快速上手

> 本篇面向**第一次接触 PLand 的服主**，带你从零开始完成：安装 → 圈地 → 购买 → 管理领地的完整流程。
> 全程约 5 分钟，建议配合 [指令](/user_guide/CommandList) 一起阅读。

## 1. 安装 PLand

PLand 有两种安装方式，**新手推荐使用 Lip 一键安装**。

```bash
lip install github.com/IceBlcokMC/PLand
```

安装完成后，启动服务器，看到下面的日志即表示安装成功：

```log
22:03:02.964 INFO [LeviLamina] PLand 已加载
```

::: tip 还没装好？
详细的安装步骤和常见问题请看 [安装指南](/user_guide/Install)。
:::

## 2. 开启圈地任务

执行：

```text
/pland new
```

插件会弹出**维度选择界面**，选择你要圈地的维度后，就进入了**圈地状态**。

::: tip 想创建子领地？
如果你想在大领地中划分小区域，使用 `/pland new sub_land`。
:::

## 3. 圈地（选择 A/B 点）

进入圈地状态后，手持**木棍**（默认选点工具，可在配置文件中修改）：

- **PC 端**：**右键**点击方块，每点击一次选定一个点（第一次为 A 点，第二次为 B 点）
- **移动端**：直接手持木棍点击方块即可

A、B 两点会框出一个**长方体**，这个范围就是你要圈的地。

::: tip 选区会自动渲染边框
开始圈地后，插件会自动绘制你选区的边界，方便确认范围。
:::

::: tip 什么是选区？
选区 = 你用木棍框出来的长方体范围。之后购买的领地就是这块区域。
想了解更详细的概念，请看 [术语表](/user_guide/Glossary)。
:::

## 4. 购买领地（买断制）

框好选区后，执行：

```text
/pland buy
```

弹出**购买确认界面**，确认后你的领地就**创建成功**了！

::: tip 什么是买断制？
**买断制** = 一次性付清价格，**永久拥有**这块领地。适合固定地盘。
:::

::: tip 提示

- 购买会**消耗游戏币**（若经济系统未启用，则免费、不消耗）
- 圈错了想重来？执行 `/pland cancel` 取消当前选区
- 价格由服务器配置中的 `formula` 价格表达式决定，详见 [领地配置文件](/user_guide/Config#formula-价格表达式)
  :::

## 5. 购买领地（租赁制）

::: tip 什么是租赁制？
**租赁制** = 按天付费，到期不续费就会被回收。适合临时地盘。
:::

如果你的服务器开启了**租赁模式**（需要服主在配置中开启），流程与买断制相同：

```text
/pland new   # 1. 开启圈地任务
/pland buy   # 2. 圈好地后执行购买
```

在购买界面中选择「**租赁模式**」，按提示选择租期并确认即可。创建后可以用 `/pland lease info` 查看当前领地的租赁信息。

::: tip 更多租赁操作（管理员）

- `/pland admin lease add_time <数量> <day|hour|min|sec>` — 给某块领地增加租期
- `/pland admin lease to_leased <天数>` — 把买断领地转为租赁领地
- `/pland admin lease to_bought` — 把租赁领地转为买断领地

完整租赁命令见 [指令](/user_guide/CommandList)。
:::

## 6. 管理你的领地

### 打开领地管理菜单

```text
/pland this
```

这个命令会在你**当前所在的领地**打开管理界面，你可以在这里：

- 查看领地信息（范围、价格、租赁状态等）
- 添加 / 移除**成员**
- 修改**领地名**
- 修改**传送点**
- 设置领地**权限**（谁可以破坏方块、谁可以使用箱子等）

### 常用指令

| 目标                               | 指令                      | 适用            |
| ---------------------------------- | ------------------------- | --------------- |
| 打开领地主菜单                     | `/pland menu`             | 所有玩家        |
| 管理当前所在领地                   | `/pland this`             | 领地主人/管理员 |
| 修改当前位置为领地传送点           | `/pland set teleport_pos` | 领地主人/管理员 |
| 手动绘制附近领地边界（需开启配置） | `/pland draw near_land`   | 所有玩家        |

::: tip 关于绘制

- 圈地时选区边框是**自动渲染**的，无需任何配置
- `/pland draw` 命令需要配置 `features.draw.enabled` 开启后才会注册，用于手动查看附近领地边界
  :::

::: tip 管理员专属命令

- `/pland admin list` — 列出/添加/移除领地管理员（控制台）
- `/pland reload` — 重新加载配置文件（控制台）

想知道所有指令？完整的指令表请查看 [指令列表](/user_guide/CommandList)。
:::
